    Notes on Quantum Computing

    This post contains some notes on quantum computing and how to simulate circuits in Python using IBM Qiskit. First some general quantum mechanics is reviewed, then it is applied to both a single qubit system and multi-qubit systems with entanglement. Finally quantum teleportation is discussed. This post will only focus on the computational aspect, the physical implementation of qubits and quantum error correction will be ignored. Quantum Mechanics and Measurement In the Schrödinger picture of quantum mechanics a quantum state is a normalized vector in a complex Hilbert space that evolves over time under the influence of constant unitary operators. This evolution is continuous in time and governed by the Schrödinger equation. The unitarity of the operators make sure the state stays normalized.     Answer Set Programming: Solving Sudoku

    Answer Set Programming is a form of declarative logic programming. You state a set of rules, defining your problem and input. The order of the rules is not relevant, they have to be satisfied as a complete set. The solver then gives you the solutions, so-called answer sets (or stable models). An answer set can be seen as a minimal set of facts that satisfy the given problem. Note that this description is very rough and imprecise.
